Лабораторная работа №1: Методы предварительной обработки данных.

Требования:
  - Python 3.10+ (https://www.python.org/downloads/)

Как запустить:

Windows:
  Дважды кликните start.bat
  (или запустите его из командной строки).

Что произойдёт:
  1. Автоматически создастся виртуальное окружение .venv.
  2. Автоматически установятся зависимости (pandas, numpy, scikit-learn, openpyxl).
  3. Запустится lab1.py.
  4. Результаты появятся в папке lab1_results.

Файлы данных должны лежать рядом со скриптом:
  - student_burnout_dropout_dataset_2-selected-columns.csv
  - 559_4.txt, 3_4.txt, 555_4.txt, 556_1.txt
