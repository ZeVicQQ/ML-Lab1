# Лабораторная работа №1: Методы предварительной обработки данных

Данный репозиторий содержит скрипт на Python для выполнения первой лабораторной работы по машинному обучению. Программа реализует основные этапы предварительной обработки данных: масштабирование, кодирование категориальных признаков, отбор признаков и обработку текстов.

## 📋 Требования к системе

- ОС: Windows (скрипт автоматизации написан на Batch).
- Python 3.10 или выше (рекомендуется 3.11 или 3.12).
- Интернет для первичной установки библиотек.

## 📦 Используемые библиотеки

Все зависимости указаны в файле `requirements.txt`:
- `pandas` — обработка табличных данных
- `numpy` — математические операции
- `scikit-learn` — масштабирование, кодирование, отбор признаков, текстовые модели
- `matplotlib` — визуализация процесса масштабирования
- `openpyxl` — экспорт результатов в формат Excel (`.xlsx`)

## 📂 Структура проекта

Перед запуском убедитесь, что в папке находятся следующие файлы и папки:

```text
├── lab1.py                 # Основной скрипт

├── datasets/               # Папка для датасетов (создается автоматически)

    ├── 3_4.txt
